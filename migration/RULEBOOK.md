# Translation Rulebook — Glean (Haskell) → Rust  [v0.3 — Step 2 round-2 amendments B1-B6 applied]

> **The meta-rule: if two agents could answer a question differently, the
> answer goes in this file.** Read by every implementer, reviewer, and fixer
> before touching code. Read-only inside any loop — amendments are queued for
> the human and applied between batches.

Read this whole document before writing any code.

## 0. Scope and posture

- **Structure-preserving** migration: same architecture, same data structures,
  same module boundaries unless a rule below says otherwise. Translating, not
  improving. (Scope amendments live in `migration/DECISIONS.md`: C++ kept via
  FFI; ALL Haskell translated, including hie-indexer.)
- Drafts do not need to compile. **Do not run `cargo build`** — it grades
  everything in Step 4. At the Step-3 gate the human may lift this ban for
  `cargo check` only (cheap-referee dissolve, README Step 4) by editing
  `.claude/settings.json`; until that edit lands the ban is absolute.
- First pass optimizes for **correct translation**, not performance. Slow but
  faithful is fine: mark `PERF(port):` + one line on the fast version.
- The old code is the spec. When unsure what the Haskell does, read it and its
  call sites — never guess from the name.
- **Bytecode identity gate (A1):** any file that emits or orders bytecode
  labels must be promoted ONLY after the old-vs-new `disassemble` identity
  check passes on that file's outputs. Label IDs are allocated at BIND (knot)
  points, never at mint points; every `x <- label` site emits its block split.

## 1. Ecosystem adoption

| Area | Decision | Why |
|---|---|---|
| Async runtime | **BANNED in all crates except `glean-server`/`glean-cli` front-ends** (tokio+hyper for the thrift-HTTP transport only). Core (core/db/storage/glass/client/…) is sync `std::thread` | Glean's server state is thread-based (MVar/TVar); an async port would rewrite, not translate |
| Concurrency primitives | `std::sync::{Mutex,RwLock,Condvar,mpsc}` + `parking_lot` if contention proves real (perf only). No async channels | mirrors MVar/TVar semantics |
| Standard I/O | `std::fs`/`std::io`. Lazy IO (hGetContents et al) is BANNED — read eagerly or buffer explicitly | source's lazy IO is a known defect source |
| Strings / bytes | `String`/`&str` (UTF-8) for `Text`; `Vec<u8>` for `ByteString`. No lossy conversions at boundaries; `Text.Encoding` errors in source become explicit `Result` | fidelity |
| Logging | glog-style logging maps to a `glean_util::log` module with LAZY message thunks (message never forced unless verbose) — mirrors Haskell laziness (A10). Show-tag parity per §2 exceptions row applies to log output | stress round-1 pilot flags |
| JSON | `serde_json` with `preserve_order`; aeson parity rules in inventory (key order, float formatting, escapes are judge-verified) | golden outputs |
| Regex | crate `regex`, NOT pcre — every `regex-pcre` import site gets an inventory row proving pattern compatibility (PCRE-only constructs → rewrite the pattern, never approximate) | pcre1 is EOL; the site count is small |
| Thrift types | generated by `build.rs` from `if/*.thrift` (never hand-translated); generated crate pinned as **`glean_thrift`** (A10). Transport: thrift binary-over-HTTP matching hsthrift's wire format — verify against a live old-server handshake in Step 5 | wire parity |
| FFI | **raw `extern "C` is the default for flat C-ABI symbols everywhere** (A2); `cxx` only when bridging C++ classes/inheritance. Vendored LMDB: raw extern "C". | flat `glean_*` symbols gain nothing from cxx (stress D13); resolves queued item 4 |
| Third-party deps | default **NONE**. Whitelist: serde, serde_json, thiserror, anyhow (binaries only), cxx (class bridges only, see FFI row), libc, regex (unused in OSS tree — see §7 item 5), parking_lot (perf), tokio+hyper (front-ends), once_cell. Time: NO time crate; `TimePoint`/monotonic → `std::time::Instant`, wall clock → `std::time::SystemTime`, durations `std::time::Duration` (B3 corrects A10's wording, which caused a wall-clock infidelity in round 2). Everything else needs a rulebook amendment | museum-of-styles prevention |
| Error model | see §2 rows on exceptions | |

**The BUG rule:** source defects reproduce bug-for-bug; mark `BUG(port):` with
a repro. Fixes ship only as flagged post-parity changes.

**The error-recovery rule:** allocation-failure ≠ structural error. Every
FFI null return in the inventory records which kind: `allocation-guard`
(abort) or `precondition-guard` (record + partial result).

**The UNKNOWN rule:** most conservative target representation + `TODO(port):`
with the open question. UNKNOWN is an answer; a stalled batch is not.

## 3. The sanctioned escape hatch

- `unsafe` allowed ONLY inside `glean-storage`/`glean-core` FFI wrappers where
  the Haskell was already FFI — never to silence the borrow checker.
- Every `unsafe` block carries `// SAFETY: <why sound>`.
- Markers (load-bearing, do not vary): `TODO(port):`, `PERF(port):`,
  `BUG(port):`, `// SAFETY:`.

## 4. Naming and output paths

- One source file → one target file: `glean/<area>/Glean/<M>.hs` →
  `rust/<crate>/src/<module.path.snaked>.rs` (module header decides; generated
  by `migration/scripts/make_manifest_haskell.py` — the manifest is
  authoritative, 383 units).
- Crates = `migration/depmap/crates.txt` (33 crates, 0 crate cycles). New
  files go to the crate of their area prefix; the partition map lives in
  `depmap_haskell.py::CRATE_PREFIXES`.
- Composition root `glean-registry` is imported by binaries only.
- Generated Rust (thrift types, schema predicate types, bytecode tables) is
  build output under `target/`/`OUT_DIR` — never in the manifest, never
  hand-written. The hand-written helpers that lived beside generated code
  (`glean/lib/Glean/Util/*`, `glean/github/{Facebook,ServiceData}`) are
  translation units in `glean-client`/`glean-fb303`.
- Imports: `use crate::glean::…` within a crate; `use glean_<crate>::…`
  across crates. No glob re-exports across crates.
- Tests: not translated (DECISIONS.md §4). Each crate's `tests/` holds
  re-expressed cases; the judge (`migration/judge/`) is the real referee.

## 5. The gap inventory

Decisions about ownership/lifetimes (FFI pointers), effect order
(unsafePerformIO), exception taxonomy, laziness, STM transactions, and JSON
parity are **not made by implementers**. They are looked up:
`migration/inventory.tsv` (one row per site). If your site isn't in the
inventory, that's an inventory bug — flag it, apply the UNKNOWN rule, keep
moving. **Diverging from a row's target_translation requires an in-file flag:
`// INVENTORY-BUG-CANDIDATE row N: <why>` (A9) — silent divergence, even
right-for-the-right-reason, is a failed review.**

## 6. Per-file obligations

Every translated file ends with:

```
// PORT STATUS: confidence=[high|medium|low] todos=[N]
```

Reviewers check the trailer against the file's actual marker count — an
undercounting trailer is a finding.
